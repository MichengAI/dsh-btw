> DSH BTW — это поддерживаемый сообществом плагин для DeepSeek Harness, не являющийся официальным продуктом DeepSeek AI. Введите `/btw ваш вопрос` в текущем диалоге, чтобы получить контекстный ответ в отдельном независимом пузыре без прерывания основной задачи. Поддерживает DSH Web и десктопные приложения на базе DSH Web. Начиная с версии `1.0.0`, неподдерживаемые версии хоста безопасно отклоняются барьером версий.

## Возможности

- **Вопросы с учетом контекста**: поясняйте концепции, подводите итоги или задавайте вопросы по текущему диалогу.
- **Только ответы, без выполнения действий**: не читает новые файлы, не выходит в сеть, не запускает системные команды и не правит код.
- **Автономные пузыри ответов**: поддержка Markdown, математических формул, копирования, сворачивания, разворачивания и закрытия.
- **Не прерывает основную задачу**: побочные вопросы обрабатываются отдельно и по умолчанию не засоряют основную ветку беседы.
- **Пересылка по требованию**: если результат нужен в основном диалоге, укажите в вопросе «отправь ответ в основной диалог», и через `send_message` будет передан цельный готовый ответ.
- **Отмена в любой момент**: закрытие пузыря во время генерации немедленно прерывает выполнение побочного вопроса.
- **Полная локализация и темы оформления**: следует светлой и темной темам DSH, нативно поддерживает все 8 официальных языков (русский, английский, китайский, японский, испанский, французский, немецкий, португальский).

## Интерфейс

### Побочный вопрос в стандартном DSH

Основной диалог остается на месте, а ответ на побочный вопрос появляется над полем ввода.

![Автономный пузырь ответа BTW в диалоге](https://raw.githubusercontent.com/MichengAI/dsh-btw/2d8dd7752cec1b29dd705969eaa932635ba0bf4f/assets/screenshots/btw-conversation.png)

### Меню команд

Введите `/` и выберите команду `btw`, либо напишите напрямую `/btw ваш вопрос`.

![Команда btw в официальном меню](https://raw.githubusercontent.com/MichengAI/dsh-btw/2d8dd7752cec1b29dd705969eaa932635ba0bf4f/assets/screenshots/btw-command-menu.png)

### Независимые пузыри ответов

Каждый вопрос выводится в отдельном блоке с кнопками копирования, сворачивания и закрытия в правом верхнем углу.

![Несколько пузырей ответов с элементами управления](https://raw.githubusercontent.com/MichengAI/dsh-btw/2d8dd7752cec1b29dd705969eaa932635ba0bf4f/assets/screenshots/btw-bubbles.png)

### Настройки побочных вопросов

Откройте **Плагины**, выберите `@michengai/dsh-btw` — форма настроек находится прямо на странице деталей: белый список инструментов и пользовательский промпт.

![Форма настроек на странице плагина](assets/screenshots/btw-settings-panel.png)

### Построение графиков и диаграмм

При добавлении `pele_draw` в белый список побочный вопрос сможет рендерить диаграммы прямо внутри своей панели, не затрагивая основной чат.

![Отрисовка блок-схем с помощью pele_draw](assets/screenshots/btw-pele-draw.png)

## Предварительные требования

- Установленный DeepSeek Harness.
- Поддерживаемые версии хоста: серия DeepSeek Harness `0.2.x` (`>=0.2.0-rc.1 <0.3.0-0`).
- Node.js 22+, доступная в консоли команда `dsh`.

## Установка

### Установка с помощью ИИ-агента (Рекомендуется)

Отправьте следующую инструкцию любому агенту, имеющему доступ к локальному терминалу:

```text
Установите плагин DSH @michengai/dsh-btw в локальный профиль web: dsh plugin --profile web add @michengai/dsh-btw@latest --registry=https://registry.npmjs.org/. После завершения выполните dsh --profile web --dump-config, чтобы убедиться в наличии michengai-btw, и расскажите, как перезагрузить DSH.
```

### Ручная установка через npm

```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$OutputEncoding = [System.Text.Encoding]::UTF8

dsh plugin --profile web add @michengai/dsh-btw@latest --registry=https://registry.npmjs.org/
```

### Перезагрузка

Выполняйте установку или обновление после завершения текущих задач. Если изменения не вступили в силу, используйте функцию перезагрузки приложения или перезапустите службу `dsh web`.

## Использование

### Вопрос по выделенному тексту

Выделите фрагмент текста в сообщении и нажмите «Спросить об этом фрагменте» на всплывающей панели. Введите вопрос и нажмите Enter или кликните «Объяснить». Shift+Enter — перенос строки, Esc — отмена.

### Вопрос через команду

```text
/btw Опиши предыдущее решение одним предложением
```

| Задача | Действие |
| --- | --- |
| Задать побочный вопрос | Введите `/btw ваш вопрос` или выберите `btw` в меню `/` |
| Просмотреть ответ | Дождитесь появления независимого пузыря над полем ввода |
| Скопировать ответ | Нажмите значок копирования в правом верхнем углу пузыря |
| Свернуть или развернуть | Нажмите значок сворачивания |
| Отменить вопрос | Закройте пузырь во время генерации (основная задача продолжится) |
| Закрыть пузырь | Закройте завершенные пузыри |

## Конфигурация

В разделе **Плагины** найдите `@michengai/dsh-btw` и нажмите **Настройки**.

| Параметр | Назначение |
| --- | --- |
| **Разрешенные инструменты** | Имена инструментов, кроме `send_message`, доступные для вызова, по одному на строку (например, `pele_draw`). Пустое поле разрешает только текст. |
| **Пользовательский промпт** | Заменяет встроенный промпт. Предзаполнен стандартным текстом для удобства правки. |

## Удаление

```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$OutputEncoding = [System.Text.Encoding]::UTF8

dsh plugin --profile web remove @michengai/dsh-btw
```
