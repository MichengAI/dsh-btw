> DSH BTW — это поддерживаемый сообществом плагин для DeepSeek Harness, не являющийся официальным продуктом DeepSeek AI. Введите `/btw ваш вопрос` в текущем диалоге, чтобы получить контекстный ответ в отдельном независимом пузыре без прерывания основной задачи. Поддерживает DSH Web и десктопные приложения на базе DSH Web. Начиная с версии `1.0.0`, неподдерживаемые версии хоста безопасно отклоняются барьером версий (установленные конфигурации и история сессий сохраняются).

## Возможности

- **Вопросы с учетом контекста**: поясняйте концепции, подводите итоги или задавайте вопросы по текущему диалогу.
- **Только ответы, без выполнения действий**: не читает новые файлы, не выходит в сеть, не запускает системные команды и не правит код.
- **Автономные пузыри ответов**: поддержка Markdown, математических формул, копирования, сворачивания, разворачивания и закрытия. Можно просматривать несколько ответов одновременно.
- **Не прерывает основную задачу**: побочные вопросы обрабатываются отдельно и по умолчанию не засоряют основную ветку беседы.
- **Пересылка по требованию**: если результат нужен в основном диалоге, укажите в вопросе «отправь ответ в основной диалог», и через `send_message` будет передан цельный готовый ответ. Без прямого указания пересылка не выполняется.
- **Отмена в любой момент**: закрытие пузыря во время генерации немедленно прерывает выполнение побочного вопроса.
- **Полная локализация и темы оформления**: следует светлой и темной темам DSH. Начиная с версии хоста 0.2.2-rc.1 нативно поддерживаются все 8 официальных языков (русский, английский, китайский, японский, испанский, французский, немецкий, португальский); на более ранних версиях 0.2.0〜0.2.1 интерфейс корректно переключается на китайский и английский.

## Интерфейс

## Предварительные требования

- Установленный DeepSeek Harness.
- Поддерживаемые версии хоста: полная линейка DeepSeek Harness `0.2.x` (`>=0.2.0-rc.1 <0.3.0-0`), проверено на `0.2.0-rc.1`, `0.2.0-rc.2`, `0.2.1-rc.1`〜`0.2.1-rc.5`, `0.2.2-rc.1`, `0.2.2-rc.2`, `0.2.2-rc.3`. Обновления в рамках поколения не требуют ожидания нового релиза плагина.
- Поддержка языков: все 8 встроенных языков доступны для выбора начиная с DeepSeek Harness `0.2.2-rc.1`. На хостах `0.2.0`〜`0.2.1` дополнительные языковые словари остаются неактивными, а интерфейс безопасно переключается на китайский и английский.
- Ранние версии до `0.2.0-rc.1` не поддерживаются. Критические изменения ветки `0.3.0` блокируются барьером версий. Пользователям `0.1.x` следует установить версию `0.1.24`.
- Node.js 22+, доступная в консоли команда `dsh`.

## Установка

Приведенные команды используют профиль `web`. Замените его на целевой профиль. Перед установкой отключите другие плагины, предоставляющие команду `/btw`.

### Установка с помощью ИИ-агента (Рекомендуется)

Отправьте следующую инструкцию любому агенту, имеющему доступ к локальному терминалу:

```text
Установите плагин DSH @michengai/dsh-btw в локальный профиль web: dsh plugin --profile web add @michengai/dsh-btw@latest --registry=https://registry.npmjs.org/. После завершения выполните dsh --profile web --dump-config, чтобы убедиться в наличии michengai-btw, и расскажите, как перезагрузить DSH и начать работу.
```

### Ручная установка через npm

```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$OutputEncoding = [System.Text.Encoding]::UTF8

dsh plugin --profile web add @michengai/dsh-btw@latest --registry=https://registry.npmjs.org/
```

### Перезагрузка

Выполняйте установку или обновление после завершения текущих задач; настольное приложение может перезагрузиться автоматически. Если изменения не вступили в силу, используйте функцию перезагрузки приложения или перезапустите службу `dsh web`. Простого обновления страницы в браузере недостаточно.

На версиях до `0.2.0` и `0.2.1` alpha установка `@latest` блокируется барьером версий. Для `0.1.x` используйте `0.1.24`. Отклонение не удаляет существующие настройки и записи сессий.

## Использование

### Вопрос по выделенному тексту

Выделите фрагмент текста в сообщении диалога и нажмите «Спросить об этом фрагменте» на верхней всплывающей панели. Введите вопрос и нажмите Enter или кликните «Объяснить». Shift+Enter — перенос строки, Esc — отмена. Ответ отобразится в автономном пузыре BTW, а исходную цитату можно развернуть.

- Поддерживает обычные абзацы, списки и блоки кода; до 8 000 символов UTF-16 на цитату (включая пробелы). При превышении лимита выводится предупреждение без обрезки текста.
- Цитата фиксируется в момент выделения и не изменяется при дальнейшей генерации текста сообщения. Остальной контекст использует завершенные данные основной сессии на момент отправки.
- Не расходует и не очищает черновик в основном поле ввода; для выделений между несколькими сообщениями, в полях ввода и в выводе инструментов меню не отображается.
- Панель также содержит пункт «Добавить в диалог», который добавляет цитату в текущий черновик и переводит фокус на поле ввода без автоматической отправки. Во время отправки сообщений добавление приостанавливается. Правый клик мыши сохраняет системное меню браузера.
- Поддерживает выделение с клавиатуры внутри текстовых элементов; при отпускании Shift фокус переходит на панель. Браузеры без поддержки Popover API переключаются на фиксированный слой (fixed).
- Разделение зон с `dsh-better-sidebar`: BTW обрабатывает только тело сообщений; предпросмотр файлов и редактор сохраняют исходную функцию боковой панели «Добавить в диалог».
- Новые элементы зависят от DOM-разметки текста хоста. В нераспознанных макетах сохраняется стандартное поведение клика правой кнопкой мыши и команда `/btw` остается доступной.

### Вопрос через команду

В диалоге с существующим контекстом введите:

```text
/btw Опиши предыдущее решение одним предложением
```

| Задача | Действие |
| --- | --- |
| Задать побочный вопрос | Введите `/btw ваш вопрос` и отправьте, либо выберите `btw` в меню `/` |
| Просмотреть ответ | Дождитесь появления независимого пузыря над полем ввода |
| Скопировать ответ | Нажмите значок копирования в правом верхнем углу пузыря |
| Свернуть или развернуть | Нажмите значок сворачивания/разворачивания |
| Отменить вопрос | Закройте пузырь во время генерации (основная задача продолжится) |
| Закрыть пузырь | Закройте завершенные пузыри |
| Задать следующий вопрос | Снова введите `/btw ваш вопрос`; каждый запрос полностью автономен |

Если требуется запустить системную команду, изменить код или продолжить главную задачу, отправьте запрос в основном диалоге. BTW отвечает исключительно на базе имеющегося контекста.

BTW принимает только текст. Если к сообщению прикреплены изображения или файлы, побочный вопрос отклоняется с сохранением текста и вложений; удалите файлы и повторите попытку.

### Инструкции по использованию

- Каждый побочный вопрос автономен и ссылается только на завершенные реплики основной сессии на момент запроса; он не включает генерируемый в текущий момент ответ или предыдущие побочные вопросы.
- При обновлении страницы пузыри не сохраняются; скопируйте нужные ответы заранее.

## Конфигурация

Оба параметра ниже необязательны. Если оставить их пустыми, сохраняется стандартное поведение: ответы только текстом и встроенный системный промпт.

Откройте **Плагины**, найдите `@michengai/dsh-btw` и нажмите **Настройки**. Страница расположена там же, где и настройки `dsh-subagent-default-model`.

| Параметр | Назначение |
| --- | --- |
| **Разрешенные инструменты** | Имена инструментов, кроме `send_message`, доступные для вызова, по одному на строку (например, `pele_draw`). Пустое поле разрешает только текст (по умолчанию). |
| **Пользовательский промпт** | Заменяет встроенный промпт. Предзаполнен стандартным текстом для удобства правки; сохранение без изменений возвращает настройки по умолчанию. |

Примечания:

- Белый список только расширяет список инструментов для побочного вопроса и никогда не ограничивает основной диалог; указание несуществующих имен инструментов ни на что не влияет.
- `send_message` нельзя вносить в белый список. Пересылка ответа в основной чат разрешена только родительской сессии побочного вопроса и не может быть перенаправлена другому агенту.
- Пользовательский промпт заменяет только вводную часть инструкций; пояснения о правах инструментов и канале отправки всегда добавляются в конец, предотвращая ложные предположения модели о доступных возможностях.
- Изменения вступают в силу со следующего побочного вопроса без перезагрузки плагина.
- Так как разрешенные инструменты упоминаются в тексте ограничений, расширение белого списка изменяет промпт побочного вопроса. Поскольку он передается в конце сообщения пользователя, определения инструментов и системный промпт остаются побайтово идентичными основной сессии, не нарушая работу prompt cache.

### Пример: рисование диаграмм в побочном вопросе

Плагин [`dsh-pele`](https://github.com/hesheng01/dsh-pele) предоставляет инструмент `pele_draw`, который рендерит код Mermaid в виде SVG-карт в диалоге. Добавив `pele_draw` в **Разрешенные инструменты**, побочный вопрос также сможет строить диаграммы.

> Примечание: `dsh-pele` — новый плагин, еще не опубликованный в npm и каталоге плагинов. Для установки клонируйте репозиторий с GitHub и добавьте папку `plugin` в профиль:
>
> ```bash
> git clone https://github.com/hesheng01/dsh-pele.git
> dsh plugin --profile <profile> add <абсолютный_путь>/dsh-pele/plugin
> ```
>
> При первой привязке требуется перезапуск Host.

## Удаление

```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$OutputEncoding = [System.Text.Encoding]::UTF8

dsh plugin --profile web remove @michengai/dsh-btw
```

Вступает в силу после перезагрузки DSH. Отключение или обновление не удаляет данные основных сессий.

## Локальная разработка

```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$OutputEncoding = [System.Text.Encoding]::UTF8
npm ci --ignore-scripts
npm run check
```

Команда `npm run check` запускает проверку типов, тесты и сборку.

Базовой версией для разработки и сборки является `0.2.2-rc.3`. Команда `npm run test:compat` компилирует проект на этой базе и запускает набор тестов в изолированных средах поддерживаемых версий хоста. Тесты компонентов DOM не заменяют проверку в реальном браузере.

GitHub и npm содержат готовый исполняемый каталог `lib`; после изменения исходного кода перед коммитом выполните `npm run build`.

Для установки из исходников выполните в каталоге проекта `dsh plugin --profile web add . --ignore-scripts` и перезагрузите DSH.
